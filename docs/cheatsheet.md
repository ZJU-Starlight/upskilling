# Markdown 语法速查

本页汇总常用 Markdown 语法。详细说明与示例见 [第三次内训](training/session-03/index.md)。

| 排版功能 | 写法 |
| --- | --- |
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 粗体 | `**重要内容**` |
| 斜体 | `*重点词语*` |
| 行内代码 | `` `practice.md` `` |
| 无序列表 | `- 一项内容` |
| 有序列表 | `1. 第一步` |
| 引用 | `> 一段引用` |
| 链接 | `[说明文字](https://example.com)` |
| 图片 | `![替代文本](images/photo.png)` |
| 已完成任务 | `- [x] 完成预习` |
| 未完成任务 | `- [ ] 完成练习` |
| 行内公式 | `$x^2$` |
| 独立公式 | 成对的 `$$` 包住公式，前后空行 |
