# 内训课程

本栏目归档社团内训资料。各课程包括教学内容、代码示例和配套练习材料。

## 第三次内训 · Markdown 写作与排版

本次课程介绍 VS Code 环境配置、Markdown 基础语法，以及 HTML、Mermaid 和数学公式的使用。配套练习以社团活动通知为例。

- **适用对象：** Markdown 初学者及需要规范笔记排版的社团成员。
- **建议用时：** 约 120 分钟，可分章节自学。
- **准备材料：** 电脑、VS Code 和课程练习文件。
- **学习成果：** 一份结构清楚、可以分享的社团活动说明书。

[进入第三次内训](session-03/index.md) · [下载与练习](session-03/exercises.md) · [语法速查](../cheatsheet.md)

## 使用说明

1. 按照环境准备页完成编辑器设置。
2. 输入并修改示例内容，核对预览结果。
3. 完成练习包中的十二道填空题，并与参考答案核对。
4. 记录练习中的问题及解决方法，形成学习记录。
