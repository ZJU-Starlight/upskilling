# 05 · LaTeX 数学公式

**目标：** 写出行内公式、独立公式，以及常见的上下标、分式和求和。

本节使用 LaTeX 的数学表达式语法，通过网页渲染器显示公式。完成这些 Markdown 练习不需要安装完整的 TeX 排版系统。

## 行内与独立公式

短表达式用一对 `$`，需要单独展示的公式用成对的 `$$`，并前后空行。

## 常用表达式

| 表达 | 源码 | 效果 |
| --- | --- | --- |
| 上标 | `x^2` | $x^2$ |
| 下标 | `x_i` | $x_i$ |
| 多字符下标 | `x_{i+1}` | $x_{i+1}$ |
| 分式 | `\frac{a}{b}` | $\frac{a}{b}$ |
| 根号 | `\sqrt{x}` | $\sqrt{x}$ |
| 求和 | `\sum_{i=1}^{n} x_i` | $\sum_{i=1}^{n} x_i$ |

多个字符属于同一个上下标时，使用 `{}` 界定范围。反斜杠开头的命令需要准确拼写。

## 活动评分的平均值

假设共有 $n$ 份评分，每份评分为 $x_i$，平均分可以写成：

```text
$$
\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}
$$
```

$$
\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}
$$

该公式仅用于排版示例，网站不执行评分计算。

## 常见错误

- `$` 或 `$$` 没有成对关闭。
- 在代码块中写公式；代码块用于展示源码，不会排版其中的数学表达式。
- 混淆普通文本格式命令与数学命令。
- 使用渲染器不支持的命令；公式语法需符合目标渲染器的支持范围。

本课使用 Markdown Preview Enhanced 打开预览，使用 Markdown PDF 导出。预览、PDF 与网站采用不同的渲染流程，需要分别核对公式的显示结果。

## 练习要求

编写包含 $n$ 的行内说明和平均分独立公式，再将分子修改为 $a+b+c$、分母修改为 $3$，检查显示结果。

完成标准：两种公式均正确显示，分子、分母和上下标的位置准确。
