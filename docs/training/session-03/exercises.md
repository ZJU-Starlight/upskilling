# 06 · 十二道填空练习

本练习包含 12 道填空题，用于检查 Markdown 基础语法、HTML、Mermaid 和数学公式的掌握情况。

![学习桌面](../../assets/images/study-desk.png)

[下载填空作业包 · ZIP](../../assets/downloads/session-03-homework.zip)

作业包包含可编辑的 `worksheet.md`、操作说明、一张本地图片，以及独立放置的参考答案。下载并解压后，即可在 VS Code 中练习；无需在线提交。

## 操作步骤

1. 下载并解压 `session-03-homework.zip`。
2. 在 VS Code 中打开解压后的整个文件夹。
3. 阅读 `README.md`，使用 Markdown Preview Enhanced 打开 `worksheet.md` 的预览。
4. 按 `Q01` 至 `Q12` 的注释提示，把每处 `___` 替换成正确语法。
5. 完成后查看 `reference/answers.md`，核对语法与渲染结果。
6. 使用 Markdown PDF 导出，并检查导出文件的排版结果。

## 题目范围

| 题号 | 练习内容 | 检查重点 |
| --- | --- | --- |
| Q01 | 一级标题 | `#` 后的空格 |
| Q02 | 粗体强调 | 标记成对出现 |
| Q03 | 无序列表 | 列表标记与空格 |
| Q04 | 有序列表 | 数字与英文句点 |
| Q05 | 超链接 | 方括号与圆括号 |
| Q06 | 本地图片 | 相对路径 |
| Q07 | 表格分隔行 | 表头与内容分开 |
| Q08 | 已完成任务 | 方括号中的状态 |
| Q09 | 代码块 | 围栏语言 |
| Q10 | HTML 折叠标题 | 标签正确关闭 |
| Q11 | Mermaid 流程图 | 围栏语言与连线 |
| Q12 | 数学公式 | 分子、分母与求和 |

## 完成后的检查清单

- [ ] 没有遗漏的 `___`。
- [ ] 标题、列表、表格和代码块显示正常。
- [ ] 图片从练习包的 `images/` 目录正确加载。
