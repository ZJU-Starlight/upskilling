# 第三次内训：Markdown 写作与排版

![学习桌面与笔记本](../../assets/images/study-desk.png)

**面向入门学习者 · 课程时长约 120 分钟 · 配套练习**

本课程介绍 Markdown 文件的编写与预览，以社团活动通知为例，讲解标题、列表、HTML 标签、流程图和数学公式的使用。

[开始学习](setup.md) · [下载填空作业包](../../assets/downloads/session-03-homework.zip) · [查看语法速查](../../cheatsheet.md)

## 学习目标

- 在 VS Code 中创建 Markdown 文件，并检查预览结果。
- 用标题、列表、链接、图片、表格和代码块组织内容。
- 用 HTML 补充排版，用 Mermaid 表达流程，用 LaTeX 语法写数学公式。
- 识别不同渲染器的显示差异，并检查最终网页效果。

## 综合任务

编写一份“社团开放日”活动说明，包括活动介绍、准备清单、报名入口、时间表和参与流程图，并添加平均分公式作为数学排版示例。

> 常用语法可在语法速查页中查询，详细说明与示例见各章节。

## 渲染兼容性

“Markdown”常被用来统称多种写作语法。表格、任务列表、Mermaid 和数学公式依赖具体渲染器；本站支持的内容，在其他平台上可能需要额外配置。课件提供源码与渲染结果对照；实际文档应在目标平台中检查显示效果。
