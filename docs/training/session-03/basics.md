# 02 · Markdown 基础

**目标：** 用清楚的结构写一份社团活动通知，掌握常见的文字、链接与代码排版。

## 标题、段落与强调

`#` 后留一个空格。标题级别表示内容层次，通常从一级标题逐层展开。段落之间空一行；普通换行不一定会变成新的段落。

```markdown
# 社团开放日

## 活动介绍

本次活动包括 **Markdown 写作** 与网页排版练习。

此段使用 *斜体* 标记重点词语。
```

效果：

本次活动包括 **Markdown 写作** 与网页排版练习。

此段使用 *斜体* 标记重点词语。

嵌套列表需要保持缩进一致。添加层级后，应检查列表的显示结果。

## 链接与图片

链接语法为 `[文字](地址)`；图片语法在前方增加 `!`，方括号中填写描述画面内容的替代文本。

```markdown
[VS Code 官方下载](https://code.visualstudio.com/download)

![学习桌面](./images/study-desk.png)
```

[VS Code 官方下载](https://code.visualstudio.com/download)

![打开的笔记本、铅笔与练习纸](../../assets/images/study-desk.png)

图片路径相对于当前 Markdown 文件。本地绝对路径（如 `C:\...`）无法直接用于其他设备；图片应随资料文件保存，并使用相对路径引用。

## 行内代码与代码块

一对反引号用于标记行内代码，例如 `practice.md`。较长的代码使用围栏，并标明语言。

````markdown
这是 `practice.md` 文件。

```python
print("Markdown example")
```
````

这是 `practice.md` 文件。

```python
print("Markdown example")
```

当示例本身含三个反引号时，展示它的外层使用四个反引号，避免围栏提前结束。

## 常见错误

| 现象 | 优先检查 |
| --- | --- |
| 标题未按标题样式显示 | `#` 后是否有空格 |
| 所有内容都变成代码 | 代码围栏是否成对关闭 |
| 图片不显示 | 路径、文件名大小写、图片是否随文档保存 |
| 表格未按列显示 | 表头下方是否有分隔行，前后是否空行 |

## 练习要求

写一份活动通知，包含：一个主标题、两个二级标题、准备清单、时间表、一个链接和一张带替代文本的图片。

完成标准：结构清楚，列表和表格显示正常，链接和图片路径有效。
