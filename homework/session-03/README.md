# 第三次内训 · Markdown 填空作业

本作业包含 12 道填空题，以“社团开放日活动通知”为文档示例，在本地完成。每处 `___` 需要替换为题目要求的语法标记或内容。

## 文件说明

- `worksheet.md`：作业文件，按 Q01 至 Q12 的注释说明填写。
- `images/study-desk.png`：图片语法练习需要的本地图片。
- `reference/answers.md`：完整参考答案，供完成作业后核对。

## 操作步骤

1. 完整解压 ZIP，保留文件与图片目录的相对位置。
2. 在 VS Code 中打开解压后的 `session-03-homework` 文件夹。
3. 打开并保存 `worksheet.md`，使用 Markdown Preview Enhanced 打开预览。
4. 按 Q01 至 Q12 的注释说明，将每题下方的 `___` 替换为相应内容。部分题目包含多个空。
5. 检查全部填空处及预览结果，确认没有保留 `___`。

本作业使用 Markdown Preview Enhanced（`shd101wyy.markdown-preview-enhanced`）打开预览，使用 Markdown PDF（`yzane.markdown-pdf`）导出。预览、PDF 与网站采用不同的渲染流程，需要分别核对图片、流程图和数学公式的显示结果。
